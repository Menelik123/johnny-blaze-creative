# Johnny Blaze Creative

Animated portfolio website for Johnny Blaze Creative (Port Harcourt).

Live preview: https://johnny-blaze-creative.vercel.app

## What's inside

- `index.html` : the full one-page site
- `style.css` : all styling and animations
- `main.js` : interactive effects (scroll reveals, cursor, gallery lightbox, contact form)
- `thank-you.html` : page shown after the contact form is sent
- `images/` : logo, founder photo and gallery work

No build step and no frameworks. It is plain HTML, CSS and JavaScript.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy it

Drag the folder onto Netlify or Vercel, or connect this repo to either one. The contact form works on Netlify Forms; on other hosts it falls back to WhatsApp.
